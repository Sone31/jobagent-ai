🤖 JobAgent AI — Privacy Policy

Last updated: June 2026  |  Effective immediately

🔒 Summary: JobAgent AI does NOT collect, transmit, sell, or share your personal data. All information you enter stays on your device. The only external calls made are to Google's Gemini API using your own API key.

📋 1. Overview

JobAgent AI ("the Extension") is a Chrome browser extension that helps users automatically fill job application forms on websites such as LinkedIn, Indeed, Seek, Glassdoor, and others, using Google Gemini AI.

This Privacy Policy explains what data the Extension handles, how it is stored, and how it is used. We are committed to protecting your privacy and being fully transparent about our data practices.

📦 2. Data the Extension Handles

The Extension allows users to store the following information locally on their own device to enable auto-filling of job applications:

  • Full name, email address, phone number
  • Location / address
  • LinkedIn URL and portfolio/website URL
  • Current job title, years of experience
  • Skills, work history summary
  • Education details (degree, institution, graduation year)
  • Certifications and languages
  • Salary expectation, notice period, visa/work status
  • Custom answers to common application questions
  • Google Gemini API key (stored locally, encrypted)
⚠️ All of the above data is stored exclusively in chrome.storage.local on the user's own device. It is never transmitted to any server operated by JobAgent AI.

🔍 3. How Your Data is Used

🤖 4. Google Gemini API

The Extension uses the Google Gemini API for AI-powered features including form field matching, resume parsing, and cover letter generation.

  • Users provide their own personal Gemini API key — the Extension does not use a shared or developer key.
  • Data sent to the Gemini API is governed by Google's Privacy Policy and Gemini API Terms of Service.
  • JobAgent AI has no access to, and does not store, any data that passes through the Gemini API.
The Extension only communicates with generativelanguage.googleapis.com (Google's Gemini API endpoint). No other external servers are contacted.

💾 5. Data Storage & Security

  • All user profile data is stored using chrome.storage.local — a secure, sandboxed storage API provided by Chrome that only the Extension can access.
  • Data is stored only on the user's local device and is never uploaded to any external server, database, or cloud service operated by JobAgent AI.
  • The Gemini API key is stored locally and is only transmitted directly to Google's API endpoint over HTTPS.
  • Users can delete all stored data at any time from the Extension's Settings tab → "Clear All Data".

🚫 7. Data We Do NOT Collect or Share

JobAgent AI does not:

  • Collect, store, or transmit your personal data to any server we operate
  • Sell, rent, or share your data with any third parties
  • Use your data for advertising or marketing purposes
  • Track your browsing history or job search activity
  • Use analytics or telemetry tools
  • Set any cookies on any website

👤 8. Your Rights & Control

You have full control over your data at all times:

  • View your data: All stored data is visible in the Extension's Profile and Settings tabs
  • Edit your data: Update any profile field at any time
  • Export your data: Use "Export Profile (JSON)" in Settings to download your data
  • Delete your data: Use "Clear All Data" in Settings to permanently delete everything
  • Uninstall: Removing the Extension from Chrome automatically deletes all locally stored data

👶 9. Children's Privacy

JobAgent AI is designed for adults seeking employment. The Extension is not directed at children under the age of 13, and we do not knowingly collect information from children.
